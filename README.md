# Untappd Toolbar Website

This is the landing page for the Untappd Toolbar extension. It showcases the features of the extension and provides installation instructions.

## Live Site
[https://untappd-toolbar-web.vercel.app](https://untappd-toolbar-web.vercel.app) (Once deployed)

## Features
-   **CSS Animations**: A pure CSS mock toolbar that scrolls to demonstrate the functionality.
-   **Responsive Design**: Works on desktop and mobile.
-   **Vercel Ready**: Includes `vercel.json` for easy deployment.

## Installation for Development
1.  Clone the repo.
2.  Open `index.html` in your browser.

## Deployment
This site is configured for automatic deployment with Vercel.
1.  Import this repository into Vercel.
2.  Deploy.
